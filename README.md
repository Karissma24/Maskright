# Maskright
A secure cloud app that collects personal data, encrypts and masks it in AWS, and displays only safe, anonymized information through a Streamlit dashboard.
# Maskright - Query Lambda for Aarati

This branch adds a **Query Lambda function** for Aarati, implementing **masking logic** for secure access to personal data.

## Features in this branch

- Lambda function that queries personal data from AWS.
- Applies masking/encryption logic before returning results.
- Ensures sensitive information is anonymized in the Streamlit dashboard.
- Tested with recent pushes
